# Public Beta

UI components for Lynx apps

> Customizable, animated and typed. Install one package and use it.

[Get Started](/guide/get-started/installation) | [API Reference](/apis/modal)

## Features

- /icons/icon-lynx-native.svg **Built for Lynx**: Written with Lynx elements and events (view, text, bindtap), so it renders natively on Android and iOS.
- /icons/icon-tailwind.svg **Tailwind, precompiled**: Styled with Tailwind v3 at build time. Your app does not need Tailwind, and every class uses an lk- prefix so nothing clashes.
- /icons/icon-controlled.svg **Controlled API**: You own the state. Pass visible and onClose, and the component never surprises you.
- /icons/icon-colors.svg **Easy to theme**: Override the accent, surface and overlay colors with plain props, or extend the classes.
- /icons/icon-typed.svg **Typed**: Ships TypeScript declarations, so props autocomplete in your editor.
- /icons/icon-animated.svg **Animated**: Enter and exit transitions are built in, driven by a small presence hook.
