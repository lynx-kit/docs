## What is Lynx Kit?

Lynx Kit is a growing collection of UI components for [Lynx](https://lynxjs.org) apps. Each component is
published as its own package under the `@lynx-kit` scope, so you install only what you use.

Today the kit contains one component:

| Package | Description |
| --- | --- |
| [`@lynx-kit/modal`](/apis/modal) | A customizable, animated modal dialog |

More components, such as a bottom sheet, are planned.
