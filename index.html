    UI components for Lynx apps

    Customizable, animated and typed. Install one package and use it.

    Get StartedAPI Reference

    Install a component

    Built for Lynx

    Written with Lynx elements and events (view, text, bindtap), so it renders natively on Android and iOS.

    Tailwind, precompiled

    Styled with Tailwind v3 at build time. Your app does not need Tailwind, and every class uses an lk- prefix so nothing clashes.

    Controlled API

    You own the state. Pass visible and onClose, and the component never surprises you.

    Easy to theme

    Override the accent, surface and overlay colors with plain props, or extend the classes.

    Typed

    Ships TypeScript declarations, so props autocomplete in your editor.

    Animated

    Enter and exit transitions are built in, driven by a small presence hook.
