    #Styling and theming

    Lynx Kit components are styled with Tailwind CSS v3, compiled when the library is built. That has three consequences for you:

    1. Your app does not need Tailwind for the components to look right.
    2. Every class inside the library starts with lk-, for example lk-bg-white, so the library cannot clash with your own classes.
    3. There are no CSS variables to configure in the host app.

    #Change colors with props

    The quickest way to theme a component is through its color props. They accept any CSS color and are applied inline:

    <Modal
  visible={open}
  onClose={() => setOpen(false)}
  title="Sign out?"
  confirmText="Sign out"
  accentColor="#0ea5e9"
  surfaceColor="#0f172a"
  overlayColor="rgba(0, 0, 0, 0.7)"
/>
    PropWhat it changes
    accentColorThe icon badge and the confirm button
    surfaceColorThe card background
    overlayColorThe dimmed backdrop

    #Extend with classes

    Every component accepts className for the card and overlayClassName for the backdrop. These classes are added after the defaults.

    If your app uses Tailwind v3, use the ! (important) modifier to win over a default:

    <Modal className="!bg-slate-900" overlayClassName="!bg-black/80" visible={open} onClose={close} />

    Those classes are generated by your Tailwind build, not the library's, so the app must have Tailwind configured. Otherwise, use the color props above.

    #Using Tailwind in your own Lynx app

    Lynx currently requires Tailwind CSS v3. The v4 packages are not compatible with @lynx-js/tailwind-preset, which removes the utilities Lynx does not support and swaps in Lynx-specific alternatives. The preset is still marked unstable.

    pnpm add -D tailwindcss@^3 @lynx-js/tailwind-preset
    postcss.config.mjs
    export default { plugins: { tailwindcss: {} } };
    tailwind.config.mjs
    import lynxPreset from '@lynx-js/tailwind-preset';

export default {
  content: ['./src/**/*.{js,ts,jsx,tsx}'],
  presets: [lynxPreset],
};
    src/App.css
    @tailwind base;
@tailwind utilities;

    #Animation

    Animation values (opacity, scale, translate and duration) are inline styles, because they change with state and not every Tailwind transition or transform utility is supported by the Lynx preset.
